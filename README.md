# 🎓 المرشد الأكاديمي الذكي - جامعة بوليتكنك فلسطين

مساعد ذكي بتقنية **RAG** يجيب الطلبة عن أسئلتهم الأكاديمية (التعليمات، الخطط الدراسية، الامتحانات) **من مستندات الجامعة الرسمية فقط**، بالفصحى أو باللهجة، ويذكر **المصدر ورقم المادة أو المساق**، ويرفض الإجابة ويُحيل للجهة المختصة عندما لا تكون المعلومة موجودة.

متوفر كـ **موقع ويب** (Gradio) و**بوت تيليجرام**، والاثنان يعملان على نفس النظام.

> **المشكلة:** المعلومة الأكاديمية موجودة لكنها موزعة بين التعليمات والخطط الدراسية والإعلانات، والطلبة يسألون بلهجتهم، والإجابة الخاطئة مكلفة (فصل إضافي أو إنذار أكاديمي). [أضيفوا هنا نتيجة الاستبيان أو الإحصائية مع مصدرها]

## التشغيل (Windows)

</div>

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env          # then put GEMINI_API_KEY (and TELEGRAM_BOT_TOKEN) in .env
python ingest.py                # builds the ChromaDB vector database from documents/
python app.py                   # web app on http://127.0.0.1:7860
python telegram_bot.py          # optional: Telegram bot
```

<div dir="rtl">

على Mac/Linux: `source .venv/bin/activate` و`cp` بدل `copy`. أول تشغيل لـ `ingest.py` ينزّل نموذج الـ Embeddings مرة واحدة.

| الأمر | ماذا يفعل |
|---|---|
| `python generator.py` | محادثة في الطرفية |
| `python retriever.py "سؤال"` | يعرض المقاطع المسترجعة ومسافاتها |
| `python ingest.py --preview documents/file.txt` | يعرض كيف سيُقطَّع ملف قبل فهرسته |
| `python evaluate.py --retrieval-only` | تقييم البحث فقط (مجاني) |
| `python evaluate.py` | التقييم الكامل للأسئلة الـ 15 ويسجل النتيجة في `eval_log.csv` |

## أمثلة

**سؤال:** هل بقدر أسحب مادة بعد الأسبوع الرابع؟
**إجابة:** نعم، الانسحاب بعد الأسبوع الأول وحتى نهاية الأسبوع العاشر يُسجَّل W ولا يدخل في المعدل الفصلي، مع فقد رسوم المساق، بشرط ألا ينخفض العبء عن الحد الأدنى.
**المصدر:** تعليمات الدراسة لدرجة البكالوريوس، المادة (7)

**سؤال:** معدلي 60% وأنا سنة ثالثة، كم ساعة أقدر أسجل؟
**إجابة:** معدلك أقل من 65% فأنت تحت التحذير الأكاديمي، ويُسمح لك بـ 15 ساعة كحد أعلى (وقد يُسمح بـ 18 في آخر فصل إذا توقف تخرجك على ذلك).
**المصدر:** تعليمات الدراسة لدرجة البكالوريوس، المادة (4) والمادة (14)

**سؤال غير موجود:** متى امتحان الخوارزميات؟
**إجابة:** لا أجد هذه المعلومة في المستندات المتاحة لي. يُرجى مراجعة جدول الامتحانات الرسمي.

## المعمارية

</div>

```
documents/*.txt (header: SOURCE_TITLE, SOURCE_URL, DEGREE, VERIFICATION)
   │  ingest.py     clean Arabic (NFKC, tatweel, Arabic-Indic digits) → line-aware chunks (400 chars,
   │                1-line overlap, section title repeated) → metadata: title, url, degree
   ▼
ChromaDB (on disk, cosine) + multilingual embeddings (paraphrase-multilingual-MiniLM-L12-v2)
   │  retriever.py  dialect→formal query expansion → degree metadata filter → semantic + BM25
   │                → RRF fusion → top-6 → distance gate (refuse if > 0.62)
   ▼
generator.py        strict academic-advisor prompt (context only, cite article/course, 2 refusal types,
   │                degrees & plan years kept apart) → Gemini (gemini-3.6-flash)
   ▼
app.py (Gradio web, Arabic RTL, upload tab)   telegram_bot.py (Telegram, per-user history)
```

<div dir="rtl">

| الملف | الطبقة |
|---|---|
| `ingest.py` | الاستيعاب: القراءة، تنظيف العربية، التقطيع، التخزين في ChromaDB |
| `retriever.py` | الاسترجاع: توسيع اللهجة، تصفية الدرجة، البحث الهجين، بوابة الرفض |
| `generator.py` | التوليد: الـ Prompt، الاتصال بالموديل، المصادر |
| `app.py` / `telegram_bot.py` | الواجهتان |
| `evaluate.py` + `tests.json` | التقييم (15 سؤالًا من 7 أنواع) |

الإعدادات في أعلى كل ملف تحت `SETTINGS`. **لإضافة أو تعديل بيانات:** ضع ملفًا في `documents/` (أو عدّل سطرًا) ثم `python ingest.py`، بلا أي تعديل في الكود. أو ارفع الملف من تبويب "إضافة مستندات" في الموقع.

## القرارات التقنية ولماذا

- **ChromaDB** محليًا (على القرص) مع **cosine**: نحسب المتجهات مرة واحدة، ومدى المسافة ثابت (0-2) فيسهل وضع حد الرفض.
- **Embeddings متعدد اللغات** يدعم العربية ويعمل محليًا بلا تكلفة (نموذج Chroma الافتراضي إنجليزي فقط).
- **التقطيع حسب السطر:** كل مادة أو مساق في سطر، فلا تنقسم مادة أو مساق في منتصفه، وعنوان القسم يتكرر في كل مقطع.
- **توسيع اللهجة:** قاموس صغير يضيف الكلمات الرسمية للسؤال ("غبت" ← الغياب الحرمان، "منذر" ← التحذير الإنذار).
- **تصفية حسب الدرجة (Metadata Filtering):** إذا ذُكر "دبلوم" أو "ماجستير" نبحث في مستنداتها فقط، فلا تختلط علامة النجاح 50% بـ 60%.
- **بحث هجين + RRF:** البحث الدلالي يفهم المعنى، وBM25 يلتقط أرقام المساقات والمواد.
- **نوعان من الرفض:** خارج النطاق (اعتذار وحدود العمل، دون استدعاء الموديل) وغير موجود في المستندات (رفض + إحالة للجهة المختصة).
- **Gemini 3.6 Flash:** طبقة مجانية، عربية قوية. رفعنا حد التوكنز إلى 4000 لأن الموديل "يفكر" قبل الإجابة وكانت الإجابات تُقطع عند 900.
- **تبديل تلقائي للموديل:** لكل موديل حصة مجانية منفصلة؛ إذا نفدت حصة الموديل الأساسي (خطأ 429) أو كان مشغولًا، ينتقل النظام تلقائيًا إلى `gemini-3.5-flash-lite` بدل أن يتعطل.

## التقييم

**تجارب الاسترجاع** (10 أسئلة، هل المقطع الصحيح ضمن النتائج؟) - `retrieval_experiments.csv`:

| التجربة | النتيجة |
|---|---|
| خط الأساس (مقطع 800، k=4) | 6/10 |
| تصغير المقطع إلى 400 | 7/10 |
| + توسيع اللهجة | 8/10 |
| + تصحيح توسيع كلمة "أتخرج" | 9/10 |
| + k = 6 | **10/10** |

**التقييم الكامل** (15 سؤالًا: مباشر، لهجة، جدول، متعدد المستندات، تعارض نسختين، غير موجود، خارج النطاق) - `eval_log.csv`:

| المقياس | النتيجة |
|---|---|
| Hit@6 (المقطع الصحيح ضمن النتائج) | **100%** (12/12) |
| Precision@6 | 46% |
| الإجابات الصحيحة | 10/12 |
| الرفض الصحيح (غير موجود + خارج النطاق) | **3/3** |
| **المجموع** | **نجح في 13 من 15** |

**أسوأ الأسئلة ولماذا:** فشل السؤالان اللذان يحتاجان **الجمع بين أكثر من مادة**: "معدلي 60% وأنا سنة ثالثة، كم ساعة أقدر أسجل؟" و"ما الفرق في علامة النجاح بين الدبلوم والبكالوريوس؟". المقاطع الصحيحة كانت ضمن النتائج (الاسترجاع نجح)، لكن هذا التشغيل تم بالموديل الاحتياطي الأخف (`gemini-3.5-flash-lite`) بعد نفاد حصة الموديل الأساسي المجانية؛ فأجاب عن الأول دون استنتاج حد الـ 15 ساعة للمحذَّر، ورفض الثاني رغم وجود المادتين. في تجربة سابقة بالموديل الأساسي (`gemini-3.6-flash`) أُجيب السؤال الأول صحيحًا (15 ساعة). **الخطوة التالية:** موديل أقوى أو مفتاح بحصة أكبر، وإعادة ترتيب النتائج (Reranking).

## الأمان والخصوصية

- المفاتيح في `.env` فقط (مستثنى في `.gitignore`)، ويوجد `.env.example` بلا مفاتيح.
- الـ Embeddings وChromaDB تعمل محليًا؛ لا يُرسل للموديل إلا المقاطع المسترجعة والسؤال.
- لا نخزن بيانات شخصية للطلبة، والنظام لا يطلب السجل الدراسي.
- طلبات الطبقة المجانية من Gemini قد تستخدمها Google لتحسين منتجاتها؛ في المنتج الحقيقي ننتقل للطبقة المدفوعة أو لموديل محلي.

## الحدود المعروفة

- البيانات حاليًا: تعليمات الدرجات الثلاث (ملخصات) وخطة علم الحاسوب فقط. الخطط الأخرى ودليل الطالب الكامل والتقويم الأكاديمي غير مضمّنة بعد.
- النظام لا يحسب الساعات المتبقية لطالب بعينه (يحتاج سجله الدراسي).
- الإجابات ليست مضمونة 100%، لذلك نعرض المصدر والرابط دائمًا.

## إفصاح استخدام الذكاء الاصطناعي

استخدم الفريق **Claude** (Anthropic، عبر Claude Code) و**Gemini** (Google) في: كتابة الكود وتنظيمه في طبقات، واستخراج جدول الخطة من PDF، وصياغة الـ Prompt، وجمع وتلخيص تعليمات الجامعة من صفحاتها الرسمية.
راجع الفريق وقرر: اختيار المشكلة والمستندات ونطاقها، أسئلة الاختبار، التجارب وضبط الإعدادات حسب النتائج، الخطة التجارية.
كود القالب مبني على كود جلسات **BinX Tech × IEEE BU RAG Bootcamp** مع تحسينات. موديل **Gemini** هو أيضًا الذي يولّد الإجابات داخل النظام.
